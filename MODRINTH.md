# Spoty Widget

Shows the song you're playing - album art, title, artist, time, little equaliser - in the corner. No more alt tabbing to check the current song.

**No Spotify account. No API key. No login.**

![Widget Preview](https://cdn.modrinth.com/data/Fp1xKkvp/images/9ca1fb4edf3e1016a88978a6c6a90aaa5bfe432f.png)

---

**5 designs:** Classic, Progress bar, Compact, Above hotbar, Vanilla tooltip - cycle with one button. Any corner, scale 0.5x-2x.

**Controls:** next/prev track, volume up/down, under Options → Controls.

**Jukebox aware:** playing a record switches the widget to it and pauses Spotify.

---

**Requires:** Fabric Loader 0.17+, Fabric API. Mod Menu optional (settings UI). Windows/Linux only, client side only.
